# cc-satellite

管理卫星过境窗口、地面站和天线资源，并在可见过境窗口内排程卫星联系任务。

## 开发环境

- JDK 21
- Spring Boot 4.1.1
- Maven Wrapper 3.9.9
- H2

## 本地运行

启动服务：

    ./mvnw spring-boot:run

运行测试：

    ./mvnw clean test

## 领域模型

- **地面站（GroundStation）**：唯一编号、支持频段集合、若干天线。
- **天线（Antenna）**：全局唯一编号，并定义从一个卫星转向另一卫星所需的固定准备时长（秒）。
- **过境窗口（PassWindow）**：站点、卫星、开始/结束时间、可用频段。
- **联系任务（ContactTask）**：一次已排程的联系，占用某根天线的 `[startTime, endTime)`，
  状态为 `SCHEDULED` / `CANCELLED`。

## 主要业务规则

1. **窗口与频段约束**：实际联系必须完整落在过境窗口内；请求频段必须同时被窗口和地面站支持。
2. **天线占用**：同一天线上的任务时间不得重叠。
3. **转向准备**：同一天线上相邻任务属于不同卫星时，间隔必须不小于该天线的转向准备时长；
   属于同一卫星时可以首尾相接。排程时同时检查前后两个方向的相邻任务。
4. **位置选择**：在所有可行位置中，按以下顺序稳定选择——
   距离期望开始时间最近 → 开始时间更早 → 天线编号更小。
   期望时间落在窗口外时会被夹取到最近的可行位置。
5. **失败不留占用**：找不到可行位置时抛错并回滚事务，不留下任何天线占用。
6. **幂等**：排程请求携带幂等键。相同键 + 相同内容重放返回原排程（HTTP 200）；
   相同键 + 不同内容返回冲突（HTTP 409）。
7. **并发安全**：排程在事务内对地面站行加悲观写锁（`PESSIMISTIC_WRITE`），
   串行化同一站点的排程决策，并发下不会产生重叠或违反转向间隔。
8. **取消**：只能取消未开始的任务（开始时间晚于当前时间），取消后释放天线占用；
   重复取消是幂等空操作，只生效一次。当前时间来自可替换的 `Clock` Bean
   （`ClockConfig`），测试中可注入固定/可变时钟。

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/stations` | 登记地面站（编号、频段、天线及转向时长） |
| POST | `/api/windows` | 登记过境窗口 |
| POST | `/api/contacts` | 排程联系任务（幂等；新建 201，重放 200，冲突 409，不可排 422） |
| GET | `/api/contacts/{id}` | 联系详情 |
| DELETE | `/api/contacts/{id}` | 取消未开始的任务（幂等） |
| GET | `/api/stations/{code}/schedule?from=&to=` | 地面站日程（按天线编号、开始时间排序） |

时间均使用 ISO-8601 UTC 格式（如 `2026-09-27T10:00:00Z`）。
